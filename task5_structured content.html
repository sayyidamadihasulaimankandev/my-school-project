WHAT DOES WWW MEAN

WWW stands for World Wide Web, a global information system that allows users to access, view, and navigate interconnected webpages, documents, and multimedia files on the internet using a web browser

WHERE DO WEB DEVELOPERS PUBLISH THEIR WEBSITES?

Web developers publish their websites on the web to be acessed by others around the globe.

DO WE HAVE TYPES OF WEB DEVELOPERS?

Yes. There are three categories of web developers. First we have the frontend developer whose job is responsible for the content of the website. They focus on how the webpage should appear. On the other hand is also the backend developer who controls the behind the scene aspect of the webpage. Lastly the full stack developer who combines the two former skills and is able to build a whole website from start to finish.
